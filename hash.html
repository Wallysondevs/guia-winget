Hash de Arquivos (hash)

O hash é a impressão digital de um arquivo: qualquer mudança, até de uma letra, gera outro valor. O winget usa o SHA-256 para conferir instaladores, e o comando hash calcula esse valor para você.

Você vai aprender
  • Calcular o SHA-256 com winget hash.
  • Para que serve o hash num manifesto.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. Calculando

Na pasta de testes, há um arquivo ola.txt com a frase Olá, winget!:

PS C:\Users\ana\AppData\Local\Temp\guia-winget> winget hash ola.txt
InstallerSha256: b8dc0b9f6d4545698de096f76e775c0a30f40d452df99c8fb9cc7c90890d4a68

A resposta já vem no formato do manifesto: InstallerSha256: seguido dos 64 caracteres hexadecimais, em minúsculas. É essa linha que vai no manifesto (veja o exemplo na aula Manifestos YAML: o mesmo hash aparece lá em maiúsculas, porque o script de coleta o calculou com Get-FileHash; para o hash, maiúsculas e minúsculas não fazem diferença).

2. Para que serve

  • Quem publica um pacote calcula o hash do instalador e põe no manifesto.
  • Quem instala recebe o arquivo, o winget calcula o hash de novo e compara. Se não bater, a instalação para.

No PowerShell, Get-FileHash arquivo também calcula o SHA-256 de um arquivo.
