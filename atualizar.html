Atualizando (upgrade)

Programas desatualizados são a porta de entrada de muitos problemas de segurança. O winget mostra o que tem versão mais recente e atualiza pacote por pacote.

Você vai aprender
  • Ver se um pacote tem atualização com --upgrade-available.
  • Atualizar um pacote com winget upgrade --id.
  • Por que evitar upgrade --all sem olhar.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.
O pacote de teste

Todas as aulas deste nível usam o jq (jqlang.jq), um programa de linha de comando para ler JSON, com cerca de 1 MB. Ele é portable e fica só na sua conta (--scope user). Use um terminal comum, sem administrador: na coleta deste guia, a sessão de administrador impediu a remoção (aula Desinstalando).

1. Tem atualização?

PS C:\Users\ana> winget list --id jqlang.jq --exact --upgrade-available
Nenhum pacote instalado foi encontrado que corresponda aos critérios de entrada.

--upgrade-available faz o list considerar só pacotes com versão mais recente no catálogo. O jq estava instalado na versão 1.8.2, a mais recente, então nenhum pacote passou no filtro. Repare em dois detalhes da resposta real: a mensagem é a mesma de pacote ausente (Nenhum pacote instalado foi encontrado...), mesmo com o jq instalado, e o código de saída foi 0. Leia essa mensagem pensando no filtro: aqui ela quer dizer “nada para atualizar”.

2. Atualizando um pacote

PS C:\Users\ana> winget upgrade --id jqlang.jq --exact --disable-interactivity
Nenhuma atualização disponível foi encontrada.
Nenhuma versão de pacote mais recente está disponível nas origens configuradas.

Com o pacote já na última versão, o upgrade só confere e avisa que não há o que atualizar. O código de saída, porém, não é zero: foi 0x8A15002B (-1978335189). Um script que trate todo código diferente de zero como falha vai ver uma falha aqui. Quando houver versão mais recente, o mesmo comando baixa e instala.

3. E o upgrade sozinho?

winget upgrade sem argumentos lista tudo o que tem atualização no computador (de novo, uma lista que revela seus programas; o guia não mostra). winget upgrade --all atualiza tudo de uma vez: prático, mas atualiza também o que você talvez quisesse segurar. Prefira olhar a lista e atualizar pelo ID, e use pin nos que não podem mudar.

Referência rápida

Você escreveO que faz
winget list --upgrade-availableo que tem atualização
winget upgrade --id ID --exactatualiza um pacote
winget upgrade --allatualiza tudo (cuidado)

Exercícios

1. Só os desatualizados

Complete para listar só pacotes com atualização.

winget list --id jqlang.jq --exact --

2. O upgrade do jq terminou com 0x8A15002B. O que aconteceu?

Missão: Verifique se o jq tem atualização disponível, sem atualizar nada.

winget list --id jqlang.jq --exact

winget list --id jqlang.jq --exact --upgrade-available

Nenhum pacote instalado foi encontrado que corresponda aos critérios de entrada.

Missão: Peça a atualização só do jq, pelo ID exato e sem perguntas.

winget upgrade

winget upgrade --id jqlang.jq --exact --disable-interactivity

Nenhuma atualização disponível foi encontrada.
Nenhuma versão de pacote mais recente está disponível nas origens configuradas.

Resumo

  • list --upgrade-available mostra o que pode ser atualizado; sem nada, responde com a mensagem de pacote não encontrado e código 0.
  • upgrade --id ... --exact atualiza um pacote; sem atualização, termina com 0x8A15002B.
  • upgrade --all só depois de olhar a lista.
