winget em Scripts do PowerShell

O winget brilha em scripts: preparar um computador, instalar as ferramentas de um curso, conferir se algo está instalado. A peça-chave é o código de saída.

Você vai aprender
  • Testar se um pacote está instalado num if.
  • Montar um script que instala só o que falta.
  • As opções que um script sempre deve usar.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. Está instalado?

Na primeira coleta, antes de instalar o jq:

PS C:\Users\ana> winget list --id jqlang.jq --exact *> $null; if ($LASTEXITCODE -eq 0) { 'jq está instalado' } else { 'jq não está instalado' }
jq não está instalado

Na coleta do ciclo completo, com o jq instalado (a remoção tinha falhado, aula Desinstalando):

PS C:\Users\ana> winget list --id jqlang.jq --exact *> $null; if ($LASTEXITCODE -eq 0) { 'jq está instalado' } else { 'jq não está instalado' }
jq está instalado

O *> $null descarta toda a saída (normal e de erro); só o código interessa. Sem o jq, o list terminou com código diferente de zero; com ele, com 0.

2. Instalar só se faltar

Juntando o teste com uma instalação segura (ID exato, fonte, escopo de usuário e sem perguntas):

$pacotes = 'jqlang.jq'
foreach ($id in $pacotes) {
    winget list --id $id --exact *> $null
    if ($LASTEXITCODE -eq 0) {
        "$id já está instalado"
        continue
    }
    winget install --id $id --exact --source winget --scope user `
        --accept-source-agreements --accept-package-agreements --disable-interactivity
    if ($LASTEXITCODE -ne 0) { "falhou: $id (código $LASTEXITCODE)" }
}

Este script não foi rodado no computador onde as saídas foram colhidas (ele instalaria o jq); as opções dele aparecem na ajuda real do install (aula Contratos e Modo Não Interativo).

3. Regras para scripts

  • Sempre --id ... --exact e --source.
  • Sempre --disable-interactivity e os --accept-... que fizerem sentido.
  • Sempre confira $LASTEXITCODE depois de cada comando.
