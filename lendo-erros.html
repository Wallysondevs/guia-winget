Lendo Mensagens de Erro

Errar no terminal é normal. O que separa quem se vira de quem trava é ler a mensagem. Aqui estão erros reais do winget, um de cada tipo, e o que cada um quer dizer.

Você vai aprender
  • Reconhecer “nenhum pacote encontrado”.
  • Reconhecer argumento e comando não reconhecidos.
  • Reconhecer um valor inválido para uma opção.
  • Usar o código de saída para saber se deu certo.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. Pacote que não existe

Pedir um ID que não está em nenhuma fonte:

PS C:\Users\ana> winget show --id Exemplo.PacoteQueNaoExiste --exact
Nenhum pacote encontrou os critérios de entrada correspondentes.

Uma linha só: o winget procurou e não achou nada com aquele critério (a frase em português é um pouco torta, mas é exatamente o que ele escreve). Confira a grafia do ID ou procure por um pedaço do nome com winget search.

A opção --count espera um número de 1 a 1000, e é isso que a mensagem diz; abc não serve.

Ache a linha do problema

Quando o erro é de digitação, o winget repete o cabeçalho com a versão e a frase do problema vem logo depois; o resto é a ajuda. Quando o erro é de pacote, a resposta é só a frase. E todo comando termina com um código de saída: zero quando deu certo, outro número quando falhou (estes quatro erros terminaram com 0x8A150014 o primeiro e 0x8A150002 os outros três). A aula Códigos de Saída mostra como ler esse número no PowerShell.

Exercícios

1. Você digitou winget serch jq. Qual é o problema?

Missão: Provoque o erro de pacote inexistente pedindo os detalhes do ID Exemplo.PacoteQueNaoExiste, com ID exato.

winget show

winget show --id Exemplo.PacoteQueNaoExiste --exact

Nenhum pacote encontrou os critérios de entrada correspondentes.

Resumo

  • “Nenhum pacote encontrado”: confira o ID ou use search.
  • Argumento ou comando não reconhecido: o winget mostra a ajuda certa.
  • A primeira linha da resposta diz o problema.
