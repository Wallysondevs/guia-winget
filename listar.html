Listando o que Está Instalado (list)

O list mostra o que está instalado. Sem filtro, ele mostra tudo: até programas que não vieram do winget. Por isso este guia sempre filtra.

Você vai aprender
  • Saber se um pacote está instalado com list --id ... --exact.
  • Ler a resposta do list.
  • Por que não compartilhar a lista completa.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.
O pacote de teste

Todas as aulas deste nível usam o jq (jqlang.jq), um programa de linha de comando para ler JSON, com cerca de 1 MB. Ele é portable e fica só na sua conta (--scope user). Use um terminal comum, sem administrador: na coleta deste guia, a sessão de administrador impediu a remoção (aula Desinstalando).

1. O mesmo comando, três momentos

Antes de instalar o jq:

PS C:\Users\ana> winget list --id jqlang.jq --exact
Nenhum pacote instalado foi encontrado que corresponda aos critérios de entrada.

Depois de instalar:

PS C:\Users\ana> winget list --id jqlang.jq --exact
Nome ID        Versão Origem
-----------------------------
jq   jqlang.jq 1.8.2  winget

Depois da tentativa de remoção, que falhou porque o terminal era de administrador (aula Desinstalando):

PS C:\Users\ana> winget list --id jqlang.jq --exact
Nome ID        Versão Origem
-----------------------------
jq   jqlang.jq 1.8.2  winget

Quando o pacote está instalado, a resposta é uma tabela com nome, ID, versão e origem. Quando não está, é a mensagem de pacote instalado não encontrado, e o código de saída deixa de ser zero (0x8A150014, aula Códigos de Saída). A terceira resposta é igual à segunda: o jq continuou instalado.

2. A lista completa

winget list sem nada lista todos os programas que o Windows conhece, inclusive os instalados pelo site do fabricante. É útil no seu computador, mas revela tudo o que você usa: o guia não mostra essa saída. Para compartilhar, filtre:

winget list --id jqlang.jq --exact
winget list --name "Visual Studio Code"

Exercícios

1. Por que o guia não mostra a saída de winget list sem filtro?

Missão: Confira se o jq está instalado no seu Windows, filtrando pelo ID exato.

winget list

winget list --id jqlang.jq --exact

Nenhum pacote instalado foi encontrado que corresponda aos critérios de entrada.

Resumo

  • list --id ... --exact responde sobre um pacote só.
  • Instalado: uma linha de tabela. Não instalado: mensagem e código 0x8A150014.
  • A lista completa expõe todos os programas: filtre ao compartilhar.
