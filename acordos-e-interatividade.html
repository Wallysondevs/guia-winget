Contratos e Modo Não Interativo

Às vezes o winget para e pergunta: você aceita os termos desta fonte? E a licença deste pacote? Num terminal, você responde. Num script, ninguém responde, e o comando fica parado para sempre. Esta aula mostra como lidar com isso.

Você vai aprender
  • O que é o contrato de uma fonte e o de um pacote.
  • Aceitar no próprio comando com --accept-source-agreements e --accept-package-agreements.
  • Garantir que o winget nunca pare para perguntar com --disable-interactivity.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. Dois tipos de contrato

--accept-source-agreements
aceita os termos de uso das fontes (a msstore pede isso na primeira consulta).
--accept-package-agreements
aceita a licença do pacote que vai ser baixado ou instalado.
--disable-interactivity
o winget nunca para esperando resposta: se precisasse perguntar, ele segue a regra padrão ou falha.

2. Na busca

A busca da aula Buscando Pacotes já aceitava o contrato das fontes no próprio comando:

PS C:\Users\ana> winget search --id jqlang.jq --exact --accept-source-agreements
Nome ID        Versão Origem
-----------------------------
jq   jqlang.jq 1.8.2  winget

A resposta veio direto, sem pergunta: a tabela com o pacote encontrado.

3. Onde as opções aparecem

As três opções estão na ajuda do install (a mesma da aula Pedindo Ajuda):

PS C:\Users\ana> winget install --help
Gerenciador de Pacotes do Windows v1.29.380
© 2026 Microsoft. Todos os direitos reservados.

Instala o pacote selecionado, seja encontrado pesquisando uma origem configurada ou diretamente de um manifesto. Por padrão, a consulta deve corresponder a maiúsculas e minúsculas a id, name ou moniker do pacote. Outros campos podem ser usados passando sua opção apropriada. Por padrão, o comando install verificará o status do pacote instalado e tentará realizar uma atualização, se aplicável. Substitua por --force para executar uma instalação direta.

Procure estas três linhas na saída:

  --accept-package-agreements          Aceitar todos os contratos de licença para pacotes
  --accept-source-agreements           Aceitar todos os acordos de origem durante as operações de origem
  --disable-interactivity              Desabilitar os prompts interativos

Para instalar sem nenhuma pergunta, um comando junta as três, por exemplo winget install --id jqlang.jq --exact --scope user --accept-source-agreements --accept-package-agreements --disable-interactivity.

Aceitar no comando não pula a leitura: é você dizendo de antemão que leu e concorda. Os endereços dos termos aparecem no winget show: a licença no campo URL da licença e, em pacotes da Microsoft Store, no bloco Acordos (veja a ficha do Python Install Manager em Detalhes de um Pacote).

Resumo

  • Fontes e pacotes podem ter contratos.
  • As opções --accept-...-agreements aceitam no próprio comando.
  • --disable-interactivity garante que nada fica esperando resposta.
