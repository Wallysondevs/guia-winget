Instalando (install)

Hora de instalar de verdade. Você já sabe achar o pacote e ler a ficha dele; agora um comando baixa, confere e instala.

Você vai aprender
  • Conferir antes que o pacote não está instalado.
  • Instalar com ID exato, fonte e escopo de usuário.
  • Ler a saída: download, hash e resultado.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.
O pacote de teste

Todas as aulas deste nível usam o jq (jqlang.jq), um programa de linha de comando para ler JSON, com cerca de 1 MB. Ele é portable e fica só na sua conta (--scope user). Use um terminal comum, sem administrador: na coleta deste guia, a sessão de administrador impediu a remoção (aula Desinstalando).

1. Antes: ele já está aí?

PS C:\Users\ana> winget list --id jqlang.jq --exact
Nenhum pacote instalado foi encontrado que corresponda aos critérios de entrada.

O list filtrado pelo ID responde só sobre esse pacote (a aula Listando explica por que filtrar). Aqui, o jq ainda não estava instalado.

2. Instalando

PS C:\Users\ana> winget install --id jqlang.jq --exact --source winget --scope user --accept-source-agreements --accept-package-agreements --disable-interactivity
Encontrado jq [jqlang.jq] Versão 1.8.2

A saída mostra o pacote encontrado, os avisos de licença, o endereço do download, a conferência do hash e o resultado (Instalado com êxito). Como o jq é portátil, o winget também avisa que criou o comando jq (O alias da linha de comando foi adicionado) e que mudou o PATH: é preciso abrir outro terminal antes de usar o jq (aula Escopo e Portáteis).

Use um terminal comum

Este install rodou num terminal de administrador e funcionou. A remoção, no mesmo tipo de terminal, foi recusada (aula Desinstalando). Instale e remova pacotes de escopo de usuário num terminal comum.

3. Depois: conferindo

PS C:\Users\ana> winget list --id jqlang.jq --exact
Nome ID        Versão Origem
-----------------------------
jq   jqlang.jq 1.8.2  winget

Agora o list responde com uma linha de tabela: nome, ID, versão instalada e origem.

Quando dá errado

Os erros mais comuns (pacote inexistente, termo solto que escolhe outro pacote sem avisar) estão na aula Erros ao Instalar e Remover, com as mensagens reais.

Referência rápida

Você escreveO que faz
winget install --id ID --exactinstala exatamente o pacote
--scope userna sua conta
-v, --version Xuma versão específica
--silentpede ao instalador que não mostre janelas

Exercícios

1. Escopo

Complete para instalar só na sua conta.

winget install --id jqlang.jq --exact --scope

Missão: Instale o jq pelo ID exato, da fonte winget, em escopo de usuário, aceitando os contratos e sem perguntas.

winget install jq
