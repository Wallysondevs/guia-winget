Versões Disponíveis (--versions)

O catálogo guarda mais de uma versão de muitos pacotes. Saber quais existem ajuda a instalar uma versão específica ou a voltar para uma anterior.

Você vai aprender
  • Listar as versões com --versions.
  • Pedir uma versão com --version.
  • Entender o erro de versão inexistente.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. Listando as versões

PS C:\Users\ana> winget show --id jqlang.jq --exact --versions
Encontrado jq [jqlang.jq]
Versão
------
1.8.2
1.8.1
1.8.0
1.7.1
1.7
1.6

A resposta confirma o pacote e lista as versões que o catálogo conhece, da mais recente (1.8.2) para a mais antiga (1.6).

2. --versions e --version

--versions
(no plural) lista as versões disponíveis.
--version 1.8.1
(no singular, com um número) escolhe uma versão para show, install ou download.

Quando dá errado

Pedir uma versão que não está no catálogo:

PS C:\Users\ana> winget show --id jqlang.jq --exact --version 0.0.0.1
Nenhuma versão correspondente foi encontrada: 0.0.0.1

A mensagem repete o número pedido. Use --versions para ver as que existem e copie o número exatamente como aparece.

Referência rápida

Você escreveO que faz
--versionslista as versões
-v, --version Xusa a versão X

Exercícios

1. Plural ou singular?

Complete para listar as versões do jq.

winget show --id jqlang.jq --exact

Missão: Liste as versões disponíveis do pacote jqlang.jq.

winget show --id jqlang.jq --exact

winget show --id jqlang.jq --exact --versions

Encontrado jq [jqlang.jq]
Versão
------
1.8.2
1.8.1
1.8.0
1.7.1
1.7
1.6

Resumo

  • --versions lista; --version X escolhe.
  • Versão inexistente: confira a lista e copie o número exato.
