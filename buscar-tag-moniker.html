Tags, Monikers e Comandos

Além do nome e do ID, cada pacote tem etiquetas (tags), às vezes um apelido curto (moniker) e a lista dos comandos que ele instala. Dá para buscar por cada um.

Você vai aprender
  • Achar pacotes por assunto com --tag.
  • Usar o apelido curto com --moniker.
  • Descobrir qual pacote instala um comando com --command.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

Etiquetas são palavras que quem publicou o pacote escolheu para descrevê-lo, como json, cli ou editor (no winget show, elas aparecem como Marcas). A correspondência Tag: json confirma por que cada pacote veio. Ótimo para descobrir ferramentas de um assunto.

2. Pelo apelido: --moniker

PS C:\Users\ana> winget search --moniker jq
Nome  ID                Versão Correspondência Origem
-----------------------------------------------------
jq    jqlang.jq         1.8.2  Moniker: jq     winget
ajq   RicardoCabral.ajq 0.1.5  Moniker: ajq    winget
jqweb zafnz.jqweb       0.9.0  Moniker: jqweb  winget

O moniker é um apelido curto que alguns pacotes têm (o do jq é jq, como mostra a correspondência Moniker: jq). Sem --exact, a busca aceita pedaços, então vieram também ajq e jqweb; com --exact, só o apelido idêntico.

3. Pelo comando: --command

PS C:\Users\ana> winget search --command jq
Nome ID        Versão Correspondência Origem
--------------------------------------------
jq   jqlang.jq 1.8.2  Command: jq     winget

Útil quando um tutorial manda rodar um comando que você não tem: a correspondência Command: jq diz que o pacote jqlang.jq instala o comando jq.

Referência rápida

Você escreveO que faz
--tag jsonpacotes com a etiqueta json
--moniker jqpacote com o apelido jq
--command jqpacotes que instalam o comando jq

Resumo

  • --tag busca por assunto.
  • --moniker usa o apelido curto.
  • --command mostra qual pacote instala um comando.
