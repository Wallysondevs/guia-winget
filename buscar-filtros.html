Filtros da Busca (--id, --name, --exact)

Uma busca solta traz candidatos demais. Os filtros dizem ao winget em qual campo procurar, se o texto precisa ser exato, em qual fonte e quantos resultados mostrar.

Você vai aprender
  • Procurar só no ID com --id e só no nome com --name.
  • Exigir o texto exato com --exact.
  • Escolher a fonte com --source e limitar com --count.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. ID exato

Quando você já sabe o ID, --id com --exact traz um resultado só:

PS C:\Users\ana> winget search --id jqlang.jq --exact --accept-source-agreements
Nome ID        Versão Origem
-----------------------------
jq   jqlang.jq 1.8.2  winget
--id jqlang.jq
procura só no campo ID.
--exact
o ID precisa ser exatamente esse, inclusive maiúsculas e minúsculas.
--accept-source-agreements
aceita os contratos das fontes (necessário só na primeira vez).

2. Só no nome, só numa fonte

PS C:\Users\ana> winget search --name jq --source winget
Nome     ID                Versão
---------------------------------
jq       jqlang.jq         1.8.2
DotNetJq GtGOpen.DotNetJq  1.0.0
ajq      RicardoCabral.ajq 0.1.5
jqweb    zafnz.jqweb       0.9.0

--name ignora ID, etiquetas e apelidos (por isso o jqweb, que tem “jq” no nome, aparece, mas os pacotes achados só pela etiqueta, não). Com --source winget, a Microsoft Store fica de fora e a tabela nem mostra a origem, porque todos vêm da mesma fonte.

3. Limitando a quantidade

Termos populares devolvem dezenas de pacotes. --count (ou -n) corta a lista, e o winget avisa na última linha que há mais resultados:

PS C:\Users\ana> winget search python --count 5
Nome             ID                          Versão         Correspondência Origem
----------------------------------------------------------------------------------
Anaconda3        Anaconda.Anaconda3          2026.07-1      Command: python winget
Miniconda3       Anaconda.Miniconda3         py314_26.9.4-1 Command: python winget
Mambaforge       CondaForge.Mambaforge       24.11.0-1      Command: python winget
Mambaforge-pypy3 CondaForge.Mambaforge.PyPy3 24.11.0-1      Command: python winget
Miniforge3       CondaForge.Miniforge3       26.9.4-2       Command: python winget
<entradas adicionais truncadas devido ao limite de resultado>

Quando dá errado

Com --exact, maiúsculas importam: --id JQLang.JQ --exact pode não achar nada. Sem --exact, a busca aceita pedaços e não diferencia maiúsculas. E --count só aceita um número de 1 a 1000 (veja o erro real em Lendo Mensagens de Erro).

Referência rápida

Você escreveO que faz
--idprocura no ID
--nameprocura no nome
-e, --exactvalor exato
-s, --sourceescolhe a fonte
-n, --countmáximo de resultados

Resumo

  • --id e --name escolhem o campo.
  • --exact exige o texto exato.
  • --source escolhe a fonte; --count limita a lista.
