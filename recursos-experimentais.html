Recursos Experimentais (features)

Recursos novos às vezes chegam primeiro como experimentais, desligados por padrão. O comando features mostra quais existem na sua versão.

Você vai aprender
  • Listar os recursos experimentais.
  • Entender onde eles são ligados.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. O comando

PS C:\Users\ana> winget features
Os seguintes recursos experimentais estão em andamento.
Eles podem ser configurados por meio do arquivo de configurações ' winget settings '.

Recurso                 Status       Propriedade    Link
----------------------------------------------------------------------------------
Direct MSI Installation Desabilitado directMSI      https://aka.ms/winget-settings
Resume                  Desabilitado resume         https://aka.ms/winget-settings
Font                    Desabilitado fonts          https://aka.ms/winget-settings
Source Priority         Desabilitado sourcePriority https://aka.ms/winget-settings

A resposta lista os recursos experimentais da versão instalada: o nome do Recurso, o Status (todos Desabilitado aqui), a Propriedade (o nome usado no settings.json, como directMSI ou resume) e um link para a documentação. Conforme o winget evolui, recursos saem dessa lista (viram padrão ou são removidos).

2. Ligando um recurso

Como a própria saída diz, eles são configurados pelo arquivo de configurações (winget settings): na seção experimentalFeatures do settings.json (aula Configurações), com o nome da Propriedade, por exemplo "experimentalFeatures": { "resume": true }. Experimental quer dizer exatamente isso: pode mudar ou sumir na próxima versão.
