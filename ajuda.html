Pedindo Ajuda (--help)

Ninguém decora todas as opções do winget. O que se decora é como pedir ajuda: --help depois do programa ou depois de um comando.

Você vai aprender
  • Ver a lista de comandos com winget --help.
  • Ver as opções de um comando com winget search --help.
  • Ler a forma curta e a longa de uma opção (-e e --exact).
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. A lista de comandos

PS C:\Users\ana> winget --help
Gerenciador de Pacotes do Windows v1.29.380
© 2026 Microsoft. Todos os direitos reservados.

O programa utilitário de linha de comando winget permite instalar aplicativos e outros pacotes a partir da linha de comando.

uso: winget  [<comando>] [<opções>]

Os seguintes comandos estão disponíveis:
  install    Instalar um determinado pacote
  show       Mostra informações sobre um pacote
  source     Gerenciar fontes de pacotes
  search     Localizar e mostrar informações básicas de pacotes
  list       Exibir os pacotes instalados
  upgrade    Mostra e executa atualizações disponíveis
  uninstall  Desinstala um determinado pacote
  hash       Ajuda para arquivos do instalador de hash
  validate   Valida um arquivo de manifesto
  settings   Abra as configurações ou defina as configurações do administrador
  features   Mostra o status dos recursos experimentais
  export     Exporta uma lista dos pacotes instalados
  import     Instala todos os pacotes em um arquivo
  pin        Gerenciar pinos de pacote
  configure  Configura o sistema em um estado desejado
  download   Baixa o instalador de um determinado pacote
  repair     Repara o pacote selecionado
  dscv3      Comandos de recurso DSC v3
  mcp        Informações MCP

Para obter mais detalhes sobre um comando específico, passe o argumento help. [-?]

As seguintes opções estão disponíveis:
  -v,--version                Exibir a versão da ferramenta
  --info                      Exibir informações gerais da ferramenta
  -?,--help                   Mostra a ajuda sobre o comando selecionado
  --wait                      Solicita que o usuário pressione qualquer tecla antes de sair
  --logs,--open-logs          Abrir o local padrão dos logs
  --verbose,--verbose-logs    Habilita o registro em log detalhado para winget
  --nowarn,--ignore-warnings  Suprime saídas de aviso
  --disable-interactivity     Desabilitar os prompts interativos
  --proxy                     Definir um proxy a ser usado para esta execução
  --no-proxy                  Desabilitar o uso de proxy para esta execução

Mais tópicos de ajuda podem ser encontrados em: https://aka.ms/winget-command-help

A ajuda geral traz uma linha de uso, a lista de comandos (install, show, search, list, upgrade...) com uma frase sobre cada um e as opções gerais, como -v,--version e --info. Repare que os nomes dos comandos e das opções ficam em inglês, mesmo com o resto em português.

2. A ajuda de um comando

Coloque --help depois do comando para ver os argumentos e opções só dele:

PS C:\Users\ana> winget search --help
Gerenciador de Pacotes do Windows v1.29.380
© 2026 Microsoft. Todos os direitos reservados.

Pesquisas de pacotes de fontes configuradas.

uso: winget search [[-q] <query>] [<opções>]

Os seguintes nomes alternativos de comando estão disponíveis:
  find

Os seguintes argumentos estão disponíveis:
  -q,--query                  A consulta usada para pesquisar um pacote

As seguintes opções estão disponíveis:
  --id                        Filtrar resultados por id
  --name                      Filtrar resultados por nome
  --moniker                   Filtrar resultados por moniker
  --tag                       Filtrar resultados por rótulo
  --cmd,--command             Filtrar resultados por comando
  -s,--source                 Encontrar pacote usando a fonte especificada
  -n,--count                  Não mostrar mais do que o número especificado de resultados (entre 1 e 1000)
  -e,--exact                  Localizar pacote usando uma correspondência exata
  --header                    Cabeçalho HTTP de origem REST opcional do Gerenciador de Pacotes do Windows
  --authentication-mode       Especificar a preferência da janela de autenticação (silent, silentPreferred ou interactive)
  --authentication-account    Especifique a conta a ser usada para autenticação
  --accept-source-agreements  Aceitar todos os acordos de origem durante as operações de origem
  --versions                  Mostrar versões disponíveis do pacote
  -?,--help                   Mostra a ajuda sobre o comando selecionado
  --wait                      Solicita que o usuário pressione qualquer tecla antes de sair
  --logs,--open-logs          Abrir o local padrão dos logs
  --verbose,--verbose-logs    Habilita o registro em log detalhado para winget
  --nowarn,--ignore-warnings  Suprime saídas de aviso
  --disable-interactivity     Desabilitar os prompts interativos
  --proxy                     Definir um proxy a ser usado para esta execução
  --no-proxy                  Desabilitar o uso de proxy para esta execução

Mais tópicos de ajuda podem ser encontrados em: https://aka.ms/winget-command-search
search
o comando sobre o qual você quer ajuda.
--help
pede a ajuda em vez de executar.

Cada opção aparece com a forma curta (quando existe, como -e) e a longa (--exact), separadas por vírgula. A ajuda também mostra que search tem um nome alternativo, find, e que --count aceita de 1 a 1000. As duas fazem a mesma coisa: a curta é para digitar rápido; a longa, para scripts que outras pessoas vão ler.

O install tem bem mais opções, porque decide escopo, local, versão, arquitetura e modo silencioso:

PS C:\Users\ana> winget install --help
Gerenciador de Pacotes do Windows v1.29.380
© 2026 Microsoft. Todos os direitos reservados.

Instala o pacote selecionado, seja encontrado pesquisando uma origem configurada ou diretamente de um manifesto. Por padrão, a consulta deve corresponder a maiúsculas e minúsculas a id, name ou moniker do pacote. Outros campos podem ser usados passando sua opção apropriada. Por padrão, o comando install verificará o status do pacote instalado e tentará realizar uma atualização, se aplicável. Substitua por --force para executar uma instalação direta.

uso: winget install [[-q] <query>...] [<opções>]

Os seguintes nomes alternativos de comando estão disponíveis:
  add

Os seguintes argumentos estão disponíveis:
  -q,--query                           A consulta usada para pesquisar um pacote

As seguintes opções estão disponíveis:
  -m,--manifest                        O caminho para o manifesto do pacote
  --id                                 Filtrar resultados por id
  --name                               Filtrar resultados por nome
  --moniker                            Filtrar resultados por moniker
  -v,--version                         Usar a versão especificada. O padrão é a versão mais recente
  -s,--source                          Encontrar pacote usando a fonte especificada
  --scope                              Selecione instalar escopo (user ou machine)
  -a,--architecture                    Selecionar a arquitetura
  --installer-type                     Selecione o tipo de instalador
  -e,--exact                           Localizar pacote usando uma correspondência exata
  -i,--interactive                     Solicitar instalação interativa; a entrada do usuário pode ser necessária
  -h,--silent                          Solicitar uma instalação silenciosa
  --locale                             Local para usar (formato BCP47)
  -o,--log                             Local do log (se houver suporte)
  --custom                             Argumentos a serem passados para o instalador, além dos padrões
  --override                           Substituir argumentos para passar para o instalador
  -l,--location                        Local para instalar (se houver suporte)
  --ignore-security-hash               Ignorar a falha na verificação do código hash do instalador
  --allow-reboot                       Permite uma reinicialização, se aplicável
  --skip-dependencies                  Ignora o processamento de dependências de pacote e recursos do Windows
  --dependencies-only                  Instala apenas as dependências do pacote
  --ignore-local-archive-malware-scan  Ignorar a verificação de malware realizada como parte da instalação de um pacote de tipo de arquivo morto do manifesto local
  --dependency-source                  Encontre as dependências de pacotes usando a origem especificada
  --accept-package-agreements          Aceitar todos os contratos de licença para pacotes
  --no-upgrade                         Ignora a atualização se uma versão instalada já existir
  --header                             Cabeçalho HTTP de origem REST opcional do Gerenciador de Pacotes do Windows
  --authentication-mode                Especificar a preferência da janela de autenticação (silent, silentPreferred ou interactive)
  --authentication-account             Especifique a conta a ser usada para autenticação
  --accept-source-agreements           Aceitar todos os acordos de origem durante as operações de origem
  -r,--rename                          O valor para renomear o arquivo executável (portátil)
  --uninstall-previous                 Desinstalar a versão anterior do pacote durante a atualização
  --force                              Execute diretamente o comando e continue com problemas não relacionados à segurança
  -?,--help                            Mostra a ajuda sobre o comando selecionado
  --wait                               Solicita que o usuário pressione qualquer tecla antes de sair
  --logs,--open-logs                   Abrir o local padrão dos logs
  --verbose,--verbose-logs             Habilita o registro em log detalhado para winget
  --nowarn,--ignore-warnings           Suprime saídas de aviso
  --disable-interactivity              Desabilitar os prompts interativos
  --proxy                              Definir um proxy a ser usado para esta execução
  --no-proxy                           Desabilitar o uso de proxy para esta execução

Quando dá errado

Se você digitar um comando que não existe, o winget avisa e mostra a ajuda geral; se errar uma opção, mostra a ajuda daquele comando. A aula Lendo Mensagens de Erro mostra a mensagem real.

Referência rápida

Você escreveO que faz
winget --helplista de comandos
winget <comando> --helpopções de um comando
winget -?forma curta da ajuda

Resumo

  • winget --help lista os comandos.
  • winget comando --help mostra as opções daquele comando.
  • Opções têm forma curta (-e) e longa (--exact).
