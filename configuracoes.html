Configurações (settings export)

O winget tem um arquivo de configurações em JSON. Dá para ver o que está valendo sem abrir nem mudar nada.

Você vai aprender
  • Ver as configurações com winget settings export.
  • Achar o caminho do settings.json.
  • Conhecer alguns ajustes úteis.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. Vendo sem mexer

PS C:\Users\ana> winget settings export
{"$schema":"https://aka.ms/winget-settings-export.schema.json","adminSettings":{"BypassCertificatePinningForMicrosoftStore":false,"ConfigurationProcessorPath":false,"InstallerHashOverride":false,"LocalArchiveMalwareScanOverride":false,"LocalManifestFiles":false,"ProxyCommandLineOptions":false},"userSettingsFile":"C:\\Users\\ana\\AppData\\Local\\Packages\\Microsoft.DesktopAppInstaller_8wekyb3d8bbwe\\LocalState\\settings.json"}

A saída é um JSON numa linha só, com o endereço do esquema ($schema), as configurações de administrador (adminSettings, todas false aqui; o winget --info mostra as mesmas como Desabilitado, mais a DefaultProxy) e o caminho do arquivo de configurações do usuário (userSettingsFile). Em JSON, a barra invertida aparece dobrada (\\): é só o jeito de escrever uma \ dentro de texto.

2. Abrindo o arquivo

winget settings, sem mais nada, abre o settings.json no editor padrão do Windows. Lá você pode, por exemplo:

{
  "visual": { "progressBar": "rainbow" },
  "installBehavior": { "preferences": { "scope": "user" } }
}

O segundo ajuste faz o winget preferir o escopo de usuário quando você não disser nada. O guia não altera as configurações do computador onde as saídas foram colhidas; este é só um exemplo de arquivo.
