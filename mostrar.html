Detalhes de um Pacote (show)

Antes de instalar, olhe. O show mostra a ficha completa de um pacote: quem publica, o que faz, onde fica o site, a licença e qual instalador será usado.

Você vai aprender
  • Rodar winget show com ID exato.
  • Ler editor, descrição, licença e links.
  • Achar o tipo de instalador e o endereço do download.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

show
mostra os detalhes de um pacote, sem instalar nada.
--id jqlang.jq
qual pacote.
--exact
sem adivinhação: exatamente esse ID.

A primeira linha confirma o pacote encontrado: Encontrado jq [jqlang.jq], com o ID entre colchetes. Depois vêm os campos do manifesto, com os nomes em português: Versão, Fornecedor (quem publica), Moniker, Descrição, Página inicial, Licença, as Notas de Versão (o texto que o projeto escreveu, em inglês) e as Marcas (etiquetas). No fim, a parte Instaladora diz o Tipo de instalador (portable), a URL do instalador e o Instalador SHA256, o hash que o winget confere depois de baixar.

2. O que conferir antes de instalar

  • Fornecedor e página inicial: são de quem você espera?
  • Licença: livre, gratuita, paga?
  • Tipo de instalador: um portable é só um executável; um msi ou exe roda um instalador de verdade (aula Tipos de Instalador).

Quando dá errado

Sem --id e --exact, o winget decide sozinho o que o termo quer dizer, e o resultado pode não ser o que você imaginava:

PS C:\Users\ana> winget show python
Encontrado Python Install Manager [9NQ7512CXL7T]
Versão: Unknown
Fornecedor: Python Software Foundation
URL do Fornecedor: https://www.python.org/
URL de Suporte do Fornecedor: https://www.python.org/doc/

  Official release page is at https://www.python.org/downloads/latest/pymanager

  Category: Developer tools

Não deu erro (o código de saída foi zero), mas veio o Python Install Manager da Microsoft Store (ID 9NQ7512CXL7T, Tipo de instalador: msstore), não um pacote da fonte winget. Repare também no bloco Acordos, típico de pacotes da loja. Para ter certeza do pacote, procure antes com winget search e use o ID com --exact.
