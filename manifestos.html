Manifestos YAML

Por trás de cada pacote do catálogo existe um manifesto: um arquivo de texto em YAML que diz o nome, a versão, quem publica, de onde baixar e qual é o hash do instalador.

Você vai aprender
  • Ler um manifesto campo por campo.
  • Diferenciar manifesto único (singleton) e em vários arquivos.
  • Ver um manifesto com erros de propósito.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. Um manifesto de exemplo

Este é o manifesto de um pacote fictício, Exemplo.Ola, criado só para as aulas (o endereço example.com é reservado para exemplos). O hash é o do arquivo ola.txt da aula Hash de Arquivos:

PS C:\Users\ana\AppData\Local\Temp\guia-winget> type manifesto-ok\Exemplo.Ola.yaml
PackageIdentifier: Exemplo.Ola
PackageVersion: 1.0.0
PackageLocale: pt-BR
Publisher: Exemplo
PackageName: Ola Exemplo
License: MIT
ShortDescription: Pacote ficticio usado so para validar um manifesto.
Installers:
  - Architecture: x64
    InstallerType: portable
    InstallerUrl: https://example.com/ola.exe
    InstallerSha256: B8DC0B9F6D4545698DE096F76E775C0A30F40D452DF99C8FB9CC7C90890D4A68
ManifestType: singleton
ManifestVersion: 1.6.0
PackageIdentifier
o ID (Editor.Programa).
PackageVersion
a versão deste manifesto.
PackageLocale
o idioma dos textos.
Installers
a lista de instaladores: arquitetura, tipo, endereço e hash SHA-256.
ManifestType / ManifestVersion
o formato do arquivo (aqui, singleton: tudo num arquivo só) e a versão do esquema.

No repositório oficial, cada versão de pacote usa três arquivos (versão, textos e instaladores), em pastas como manifests/j/jqlang/jq/1.7.1/. O singleton é mais simples para aprender e testar.

2. Um manifesto com erros

PS C:\Users\ana\AppData\Local\Temp\guia-winget> type manifesto-erro\Exemplo.Ola.yaml
PackageIdentifier: Exemplo.Ola
PackageLocale: pt-BR
Publisher: Exemplo
PackageName: Ola Exemplo
License: MIT
ShortDescription: Manifesto com erros de proposito.
Installers:
  - Architecture: x64
    InstallerType: portatil
    InstallerUrl: https://example.com/ola.exe
    InstallerSha256: 1234
ManifestType: singleton
ManifestVersion: 1.6.0

Compare com o anterior: falta PackageVersion, o tipo portatil não existe (o certo é portable) e o hash tem 4 caracteres em vez de 64. A aula Validando Manifestos mostra o que o winget disse sobre ele (spoiler: ele só reclamou do primeiro).

Resumo

  • Manifestos são arquivos YAML que descrevem pacotes.
  • Campos-chave: ID, versão, editor, instaladores e hash.
  • singleton põe tudo num arquivo só.
