Códigos de Saída

Todo comando termina com um número: o código de saída. Zero quer dizer sucesso; qualquer outro número diz o que deu errado. É esse número que um script usa para decidir o próximo passo.

Você vai aprender
  • Ler o código com $LASTEXITCODE no PowerShell.
  • Por que os códigos do winget são números negativos grandes.
  • Converter para hexadecimal para pesquisar.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. Na prática

Este trecho de PowerShell roda dois show (um com pacote que existe, outro com pacote que não existe), joga a saída fora com > $null e mostra o código de cada um:

PS C:\Users\ana> winget show --id jqlang.jq --exact > $null; "jqlang.jq: código $LASTEXITCODE"; winget show --id Exemplo.PacoteQueNaoExiste --exact > $null; "inexistente: código $LASTEXITCODE"
jqlang.jq: código 0
inexistente: código -1978335212
> $null
descarta a saída normal do comando.
$LASTEXITCODE
variável do PowerShell com o código de saída do último programa.

O primeiro show deu certo (código 0); o segundo não achou o pacote e terminou com -1978335212.

2. Por que números tão grandes?

O winget usa códigos no formato de erro do Windows (HRESULT). Em hexadecimal, os erros do winget começam com 0x8A15. Como o primeiro bit está ligado, o mesmo número aparece negativo em decimal. Para pesquisar um código na documentação, converta para hexadecimal no PowerShell:

'{0:X8}' -f -1978335212

O -1978335212 acima é o 0x8A150014, o código de “nenhum pacote encontrado” (o script de coleta registra cada código nas duas formas). O script registrou o código de cada comando deste guia; estes foram os erros que apareceram:

Repare que o winget show python da aula Detalhes de um Pacote terminou com 0: ele achou um pacote (só não era o que se esperava). Código zero quer dizer que o comando funcionou, não que fez o que você queria.

Exercícios

1. O que significa o código de saída 0?

Missão: Rode o trecho que mostra o código de saída de um show que dá certo e de um que falha.

winget show --id jqlang.jq --exact > $null

winget show --id jqlang.jq --exact > $null; "jqlang.jq: código $LASTEXITCODE"; winget show --id Exemplo.PacoteQueNaoExiste --exact > $null; "inexistente: código $LASTEXITCODE"

jqlang.jq: código 0
inexistente: código -1978335212

Resumo

  • Zero é sucesso; outro número é erro.
  • No PowerShell, o código fica em $LASTEXITCODE.
  • Erros do winget começam com 0x8A15 em hexadecimal.
