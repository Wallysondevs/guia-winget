Boas Práticas e Segurança

O winget instala programas com um comando, e isso é ótimo até o comando instalar a coisa errada. Esta aula junta os cuidados que aparecem ao longo do guia num lugar só.

Você vai aprender
  • Pedir sempre o pacote certo (ID exato e fonte).
  • Ler o show antes de instalar.
  • Por que evitar upgrade --all sem olhar a lista.
  • O que export, import e configure fazem e por que exigem atenção.
Sobre esta aula. Esta aula não mostra saídas de comandos: é só explicação. As aulas com exemplos trazem a resposta exata do winget rodando no Windows de verdade, colhida por um script e com nomes trocados (computador NOTEBOOK, usuária fictícia ana).

1. Peça o pacote certo

Um nome como “jq” pode corresponder a vários pacotes. Para instalar exatamente o que você quer, use --id com --exact e, se quiser ser explícito sobre o catálogo, --source winget:

winget install --id jqlang.jq --exact --source winget

Antes, confira o pacote com winget show --id ... --exact: editor, página oficial, licença e tipo de instalador.

2. Instale com o mínimo de poder

  • Use um terminal comum, não “como administrador”.
  • Prefira --scope user quando o pacote oferecer: o programa fica só na sua conta.
  • Pacotes portable são os mais simples de remover: ficam numa pasta e um atalho, sem instalador do sistema.

3. Atualize olhando a lista

winget upgrade sem argumentos mostra o que tem atualização. Já winget upgrade --all atualiza tudo de uma vez, inclusive programas que você talvez preferisse manter numa versão específica. Atualize um por um pelo ID e use winget pin para segurar os que não podem mudar.

4. Cuidado com o que expõe ou altera muito

ComandoO que fazCuidado
winget list (sem filtro)lista todos os programas instaladosa lista revela tudo o que você usa; filtre com --id ao compartilhar
winget export -o arquivo.jsongrava num JSON os pacotes instaladosmesma lista completa; não publique sem revisar
winget import -i arquivo.jsoninstala todos os pacotes de um JSONinstala muita coisa de uma vez; leia o arquivo antes
winget configureaplica um arquivo de configuração (pacotes, ajustes do sistema)pode mudar muito o Windows; só rode arquivos que você leu e confia

Este guia não mostra a saída desses comandos: eles listariam os programas do computador onde as saídas foram colhidas ou alterariam o sistema.

5. Hash e contratos

O winget confere o hash SHA-256 de cada instalador baixado contra o valor do manifesto; se não bater, ele recusa. Existe uma opção para ignorar essa conferência, e ela não deveria ser usada no dia a dia. Os contratos de fonte e de pacote (--accept-source-agreements e --accept-package-agreements) existem para você ler as condições; em scripts, aceite só sabendo o que está aceitando.

Resumo

  • Use --id com --exact e confira com show antes de instalar.
  • Terminal comum e --scope user sempre que der.
  • Atualize um por um; --all só olhando a lista.
  • list, export, import e configure pedem atenção redobrada.
