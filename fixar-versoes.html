Fixando Versões (pin)

Às vezes a versão mais recente quebra algo que funcionava. O pin diz ao winget: este pacote fica como está até eu mandar mudar.

Você vai aprender
  • Listar os pacotes fixados com winget pin list.
  • Fixar com pin add e liberar com pin remove.
  • Os tipos de pin: comum, bloqueio e por versão.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.
O pacote de teste

Todas as aulas deste nível usam o jq (jqlang.jq), um programa de linha de comando para ler JSON, com cerca de 1 MB. Ele é portable e fica só na sua conta (--scope user). Use um terminal comum, sem administrador: na coleta deste guia, a sessão de administrador impediu a remoção (aula Desinstalando).

1. Há algum pin no jq?

PS C:\Users\ana> winget pin list --id jqlang.jq
Não há martcadores configurados.

Não havia nenhum (código de saída 0). Na versão em português do winget, pin virou “marcador”, e a frase vem com um erro de digitação da própria tradução (martcadores): o guia mostra a saída exatamente como o winget escreveu. Filtrando pelo ID, a resposta diz só sobre o jq; sem filtro, winget pin list mostra todos os pins da sua conta.

2. Os tipos de pin

ComandoEfeito
winget pin add --id IDpin comum: upgrade --all pula o pacote; atualizar pelo ID ainda funciona com --include-pinned.
winget pin add --id ID --blockingbloqueio: nenhuma atualização até remover o pin.
winget pin add --id ID --version 1.7.*permite atualizar só dentro da faixa de versões.
winget pin remove --id IDlibera o pacote.

O guia não cria pins no computador onde as saídas foram colhidas: pin add altera as configurações do winget. Experimente no seu, com o jq, e remova depois.

Exercícios

1. Qual pin impede qualquer atualização do pacote?

Missão: Liste os pins do pacote jqlang.jq.

winget pin

Não há martcadores configurados.

Resumo

  • pin segura a versão de um pacote.
  • --blocking bloqueia tudo; --version limita a uma faixa.
  • pin remove libera.
