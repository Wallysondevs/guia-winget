Abrindo o Terminal (PowerShell e CMD)

O winget não tem janela própria: você o usa de dentro de um terminal. Esta aula mostra onde ficam os terminais do Windows, qual escolher e como copiar e colar comandos e respostas.

Você vai aprender
  • Abrir o Terminal do Windows, o PowerShell e o Prompt de Comando.
  • Reconhecer o prompt PS C:\Users\ana>.
  • Copiar e colar no terminal sem errar.
  • Por que não abrir o terminal como administrador.
Sobre esta aula. Esta aula não mostra saídas de comandos: é só explicação. As aulas com exemplos trazem a resposta exata do winget rodando no Windows de verdade, colhida por um script e com nomes trocados (computador NOTEBOOK, usuária fictícia ana).

1. Três jeitos de abrir um terminal

  1. Terminal do Windows: clique com o botão direito no botão Iniciar e escolha Terminal (no Windows 10, procure “Terminal” no menu Iniciar; se não aparecer, ele pode ser instalado pela Microsoft Store).
  2. PowerShell: aperte Win, digite powershell e aperte Enter.
  3. Prompt de Comando (CMD): aperte Win+R, digite cmd e aperte Enter.

O winget funciona igual nos três: é um programa comum (winget.exe), não um comando de um shell específico. Este guia mostra os exemplos no PowerShell, cujo prompt começa com PS.

2. Lendo o prompt

PS
você está no PowerShell (no CMD, o prompt não tem esse PS).
C:\Users\ana
a pasta atual; nos exemplos, a pasta pessoal da usuária fictícia ana.
>
o fim do prompt: o que vem depois é o comando que você digitou.

Nos blocos de terminal deste guia, a linha que começa com PS C:\Users\ana> é o comando; as linhas de baixo são a resposta. Você digita só o comando, sem o prompt.

3. Copiar e colar

  • No Terminal do Windows e no PowerShell atual, Ctrl+V cola e Ctrl+C copia o texto selecionado (sem seleção, Ctrl+C interrompe o comando).
  • O clique com o botão direito também cola, na maioria das janelas de terminal.
  • Para copiar a resposta, selecione com o mouse e aperte Ctrl+C ou Enter (no console clássico).
Não use “Executar como administrador”

Tudo neste guia funciona num terminal comum. Instalar como administrador muda onde os programas vão parar e dá poder demais a qualquer erro de digitação. Quando um instalador realmente precisar de permissão, o próprio Windows pergunta.

4. Um teste rápido

Com o terminal aberto, a próxima aula roda o primeiro comando: winget --version. Se aparecer um número de versão, está tudo pronto.

Quando dá errado

Se o terminal responder que winget não é reconhecido como comando, o Instalador de Aplicativo não está instalado ou está desatualizado. A aula Instalação e Versão mostra como resolver.

Resumo

  • O winget roda em qualquer terminal do Windows.
