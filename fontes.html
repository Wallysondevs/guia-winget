Fontes (source list e export)

Toda busca, ficha e instalação vem de uma fonte. Saber quais fontes o seu winget usa é saber em quem ele confia.

Você vai aprender
  • Listar as fontes com winget source list.
  • Ver os detalhes de uma fonte com --name.
  • Exportar a configuração das fontes com source export.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. Quais fontes existem

PS C:\Users\ana> winget source list
Nome        Argumento                                     Especificado explicitamente
-------------------------------------------------------------------------------------
msstore     https://storeedgefd.dsx.mp.microsoft.com/v9.0 false
winget      https://cdn.winget.microsoft.com/cache        false
winget-font https://cdn.winget.microsoft.com/fonts        true

Apareceram três fontes: msstore (a Microsoft Store), winget (o repositório comunitário, com manifestos revisados publicamente no GitHub) e winget-font (um catálogo de fontes tipográficas, da mesma origem). Cada linha traz o nome, o Argumento (o endereço do catálogo) e se ela foi Especificado explicitamente: true na winget-font, o que indica que ela não entra numa busca comum, só quando pedida pelo nome.

2. Detalhes de uma fonte

PS C:\Users\ana> winget source list --name winget
Campo                       Valor
------------------------------------------------------------------
Nome                        winget
Digitar                     Microsoft.PreIndexed.Package
Argumento                   https://cdn.winget.microsoft.com/cache
Dados                       Microsoft.Winget.Source_8wekyb3d8bbwe
Identificador               Microsoft.Winget.Source_8wekyb3d8bbwe
Nível de Confiança          Trusted|StoreOrigin
Especificado explicitamente false
Atualizada                  2026-11-21 12:49:22.000

Com --name, o winget mostra a ficha da fonte em formato Campo / Valor: o tipo (no campo que a tradução chamou de Digitar, do inglês Type), o endereço, o Nível de Confiança (Trusted|StoreOrigin) e o campo Atualizada, com a data e hora em que o índice foi atualizado pela última vez (o winget atualiza esse índice sozinho; aqui, no momento da coleta).

3. Exportando

PS C:\Users\ana> winget source export
{"Arg":"https://storeedgefd.dsx.mp.microsoft.com/v9.0","Data":"","Explicit":false,"Identifier":"StoreEdgeFD","Name":"msstore","TrustLevel":["Trusted"],"Type":"Microsoft.Rest"}
{"Arg":"https://cdn.winget.microsoft.com/cache","Data":"Microsoft.Winget.Source_8wekyb3d8bbwe","Explicit":false,"Identifier":"Microsoft.Winget.Source_8wekyb3d8bbwe","Name":"winget","TrustLevel":["Trusted","StoreOrigin"],"Type":"Microsoft.PreIndexed.Package"}
{"Arg":"https://cdn.winget.microsoft.com/fonts","Data":"Microsoft.Winget.Fonts.Source_8wekyb3d8bbwe","Explicit":true,"Identifier":"Microsoft.Winget.Fonts.Source_8wekyb3d8bbwe","Name":"winget-font","TrustLevel":["Trusted","StoreOrigin"],"Type":"Microsoft.PreIndexed.Package"}

O export imprime cada fonte como um objeto JSON numa linha, com os mesmos dados em inglês (Name, Arg, Type, TrustLevel, Explicit), um formato que scripts e outras ferramentas leem com facilidade.

Fontes alteram a confiança

winget source add, remove e reset mudam de onde os pacotes vêm e pedem terminal de administrador. Uma fonte desconhecida pode servir qualquer coisa. Este guia só lê as fontes, nunca as altera.

Referência rápida

Você escreveO que faz
winget source listlista as fontes
winget source list --name wingetdetalhes de uma fonte
winget source exportfontes em JSON
winget source updateforça a atualização do índice

Resumo

  • winget e msstore são as fontes que as buscas usam; winget-font só entra quando pedida.
  • source list lista; --name detalha; export gera JSON.
  • Adicionar ou remover fontes muda em quem você confia.
