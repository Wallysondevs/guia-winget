Projeto: Ciclo Completo de um Pacote

Este projeto junta o Nível 2 numa sequência só, do “será que existe?” ao “saiu mesmo?”. Faça no seu Windows, num terminal comum, na ordem, conferindo cada resposta. As respostas abaixo são as da coleta do guia, inclusive o passo que falhou.

Você vai aprender
  • Encadear search, show, list, install, uninstall.
  • Conferir cada passo antes de seguir, inclusive a remoção.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.
O pacote de teste

Todas as aulas deste nível usam o jq (jqlang.jq), um programa de linha de comando para ler JSON, com cerca de 1 MB. Ele é portable e fica só na sua conta (--scope user). Use um terminal comum, sem administrador: na coleta deste guia, a sessão de administrador impediu a remoção (aula Desinstalando).

Passo 5. Usar (num terminal aberto depois da instalação)

PS C:\Users\ana> jq --version
jq-1.8.2

Passo 6. Remover

PS C:\Users\ana> winget uninstall --id jqlang.jq --exact --scope user --disable-interactivity --accept-source-agreements
Encontrado jq [jqlang.jq]
The package installed for user scope cannot be uninstalled when running with administrator privileges.

Na coleta, a sessão era de administrador, e o winget recusou remover o pacote de escopo de usuário (0x8A15007D, aula Desinstalando). No seu Windows, num terminal comum, rode:

winget uninstall --id jqlang.jq --exact

Passo 7. Conferir

PS C:\Users\ana> winget list --id jqlang.jq --exact
Nome ID        Versão Origem
-----------------------------
jq   jqlang.jq 1.8.2  winget

Na coleta, a conferência mostrou o jq ainda instalado: é este passo que pega uma remoção que não aconteceu. No seu Windows, depois do passo 6 num terminal comum, a resposta deve ser a do passo 3 (pacote instalado não encontrado).

Desafio

Repita o ciclo com outro pacote portable pequeno que você encontrar com winget search --tag cli. Antes de instalar, confira no show que o tipo é portable.

Resumo

  • search → show → list → install → usar → uninstall → list.
  • Cada passo tem uma resposta para conferir; foi a conferência final que revelou a remoção que falhou.
  • Instale e remova pacotes de escopo de usuário num terminal comum.
