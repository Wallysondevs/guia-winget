Buscando Pacotes (search)

Para instalar algo, primeiro você precisa achar o pacote. O search procura no catálogo pelo que você digitar e devolve uma tabela com os candidatos.

Você vai aprender
  • Rodar winget search com uma palavra.
  • Ler a tabela: nome, ID, versão, correspondência e fonte.
  • Aceitar o contrato da fonte na primeira busca.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. A primeira busca

Na primeira vez que o winget consulta a fonte msstore, ele pede que você aceite o contrato da fonte. Para não ficar parado esperando resposta, dá para aceitar já no comando com --accept-source-agreements:

PS C:\Users\ana> winget search --id jqlang.jq --exact --accept-source-agreements
Nome ID        Versão Origem
-----------------------------
jq   jqlang.jq 1.8.2  winget

Depois disso, as buscas não pedem mais nada (a aula Contratos e Modo Não Interativo explica os detalhes).

2. Buscando por uma palavra

PS C:\Users\ana> winget search jq
Nome           ID                                    Versão Correspondência Origem
----------------------------------------------------------------------------------
jq             jqlang.jq                             1.8.2                  winget
celq           IvanIsCoding.celq                     0.8.0  Tag: jq         winget
ajq            RicardoCabral.ajq                     0.1.5  Tag: jq         winget
DotNetJq       GtGOpen.DotNetJq                      1.0.0                  winget
jqweb          zafnz.jqweb                           0.9.0                  winget
PiliPlus       bggRGjQaUbCoE.PiliPlus                2.2.1                  winget
Codex 多开助手 JqyModi.CodexMultiLauncher            0.1.9                  winget
Markdownify    amitmerchant1990.electron-markdownify 1.2.0  Tag: jquery     winget
TheDesk        Cutls.TheDesk                         24.2.1 Tag: jquery     winget
winget
o gerenciador de pacotes.
search
o comando de busca.
jq
o termo procurado no nome, no ID, no apelido (moniker) e nas etiquetas.

Cada linha da tabela é um pacote. Os títulos aparecem no idioma do Windows: Nome, ID, Versão (a mais recente no catálogo), Correspondência e Origem (a fonte). A correspondência explica por que o pacote apareceu: vazia quando o termo bateu no nome ou no ID, Tag: jq quando bateu numa etiqueta (e Tag: jquery mostra que a busca aceita pedaços de palavra).

Uma busca curta como jq traz vários resultados, porque outros pacotes também têm “jq” em algum campo. Para instalar, o que importa é o ID: o do programa jq é jqlang.jq. Na busca exata acima, como só havia um resultado, a tabela nem trouxe o campo de correspondência.

Quando dá errado

Se a busca não encontrar nada, o winget responde com a mesma mensagem de “nenhum pacote encontrado” da aula Lendo Mensagens de Erro. Tente um termo mais curto ou em inglês: os nomes dos pacotes costumam estar em inglês.

Referência rápida

Você escreveO que faz
winget search jqprocura “jq” em nome, ID, moniker e etiquetas
winget search "visual studio code"termo com espaços vai entre aspas

Resumo

  • winget search termo procura no catálogo.
  • A tabela mostra nome, ID, versão, correspondência e fonte.
  • Guarde o ID: é ele que você usa para instalar.
