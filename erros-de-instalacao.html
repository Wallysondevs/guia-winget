Erros ao Instalar e Remover

Os erros de install e uninstall são parecidos com os da busca, mas com consequência: errar o pacote aqui é instalar ou remover a coisa errada.

Você vai aprender
  • Instalar um ID que não existe.
  • Remover algo que não está instalado.
  • Por que um termo solto é perigoso mesmo sem erro.
Sobre as saídas. Todas as saídas desta aula vieram do winget rodando no Windows de verdade (winget v1.29.380 | Windows 10.0.19045.0 | idioma da interface pt-BR | PowerShell 7.7.0 | 2026-11-21 12:49). Um script de coleta rodou cada comando, um por um, e gravou a resposta exata; antes de gravar, o nome do computador virou NOTEBOOK, o da pessoa virou a usuária fictícia ana (pasta C:\Users\ana) e endereços de rede viraram exemplos. As mensagens aparecem no idioma do Windows em que foram colhidas, exatamente como o winget escreveu: nunca traduzimos nem inventamos saída. Os títulos das tabelas e as mensagens podem estar em outro idioma no seu computador, e os números de versão mudam com o tempo.

1. Instalar um pacote que não existe

PS C:\Users\ana> winget install --id Exemplo.PacoteQueNaoExiste --exact --disable-interactivity
Nenhum pacote encontrou os critérios de entrada correspondentes.

2. Remover algo que não está instalado

PS C:\Users\ana> winget uninstall --id Exemplo.PacoteQueNaoExiste --exact --disable-interactivity
Nenhum pacote instalado foi encontrado que corresponda aos critérios de entrada.

Repare que a mensagem fala em pacote instalado: o uninstall procura entre os programas da máquina, não no catálogo.

As duas mensagens são diferentes, mas o código de saída é o mesmo: 0x8A150014 (aula Códigos de Saída).

Este show com um termo solto não falhou: o winget escolheu um pacote, o Python Install Manager da Microsoft Store (ID 9NQ7512CXL7T). Se fosse winget install python, a escolha seria feita do mesmo jeito, sem você conferir. Por isso a receita do guia é sempre show antes e --id ... --exact no install e no uninstall.

Exercícios

1. winget show python terminou com código 0. O que isso garante?

Missão: Tente remover o pacote inexistente Exemplo.PacoteQueNaoExiste (nada será removido).

winget uninstall

winget uninstall --id Exemplo.PacoteQueNaoExiste --exact --disable-interactivity

Nenhum pacote instalado foi encontrado que corresponda aos critérios de entrada.

Resumo

  • ID inexistente: nada é instalado nem removido (código 0x8A150014).
  • uninstall procura entre os instalados.
  • Termo solto pode escolher um pacote inesperado sem dar erro: use --id ... --exact.
