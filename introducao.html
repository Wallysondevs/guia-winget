O que é o winget

O winget é o gerenciador de pacotes oficial do Windows: um programa de linha de comando que procura, instala, atualiza e remove outros programas por você, sem abrir site, sem baixar instalador na mão e sem clicar em “Avançar” cinco vezes.

Você vai aprender
  • O que é um gerenciador de pacotes e por que ele economiza tempo.
  • De onde vêm os pacotes do winget (as fontes).
  • O que muda entre instalar pelo site e instalar pelo winget.
  • Como este guia está organizado.
Sobre esta aula. Esta aula não mostra saídas de comandos: é só explicação. As aulas com exemplos trazem a resposta exata do winget rodando no Windows de verdade, colhida por um script e com nomes trocados (computador NOTEBOOK, usuária fictícia ana).

1. O problema que ele resolve

Pense no jeito tradicional de instalar um programa no Windows: abrir o navegador, procurar o site oficial (torcendo para não cair num site falso), achar o botão de download certo para o seu sistema, baixar, executar o instalador e responder às perguntas dele. Para atualizar, você repete tudo meses depois, se lembrar.

Um gerenciador de pacotes troca esse ritual por um comando. Ele mantém um catálogo com o nome de cada programa, onde baixar o instalador, a versão mais recente e um hash (uma impressão digital do arquivo) para conferir que o download não foi adulterado. Linux e macOS usam isso há anos (apt, dnf, brew); no Windows, a ferramenta oficial é o winget.

2. Pacote, ID e fonte

pacote
um programa no catálogo, com nome, editor, versões e instaladores.
ID
o nome único do pacote, no formato Editor.Programa (por exemplo, jqlang.jq ou 7zip.7zip).
fonte
o catálogo de onde o winget lê os pacotes: winget (o repositório comunitário da Microsoft) e msstore (a Microsoft Store).

O ID é o que você vai mais usar: nomes de programas se repetem e mudam de idioma, mas o ID não. Por isso as aulas sempre mostram o jeito exato de pedir um pacote pelo ID.

3. Por que usar a linha de comando

  • Rapidez: um comando substitui vários cliques.
  • Repetição: o mesmo comando funciona em outro computador, num script ou num roteiro de instalação.
  • Segurança: o instalador vem do endereço registrado no catálogo e o winget confere o hash antes de executar.
  • Atualização: um único comando mostra o que tem versão mais recente.
O winget só existe no Windows

Ele faz parte do Instalador de Aplicativo (App Installer) do Windows 10 e 11. Todas as saídas deste guia foram colhidas num Windows de verdade; as missões pedem que você rode os comandos no seu Windows e cole a resposta na página.

4. Como o guia está organizado

O Nível 1 só lê: versão, ajuda, busca e detalhes de pacotes. Nada muda no seu computador. O Nível 2 trata do que vem antes e depois de instalar: contratos, códigos de saída e erros. O Nível 3 trata de fontes, configurações, manifestos (os arquivos que descrevem um pacote) e de como usar o winget em scripts.
